# Power BI Data Analytics & Dashboard Portfolio

## Overview

This portfolio demonstrates my practical learning and application of
Microsoft Power BI, covering data preparation, data cleaning,
data transformation, data modeling, data analysis, visualization,
dashboard design, and basic DAX.

The project demonstrates the process of transforming raw Excel data
into structured and interactive reports to support data-driven
analysis and decision-making.

---

## Project Objectives

The main objectives of this project are:

- Learn and apply Power Query for data preparation and transformation
- Clean and structure raw Excel data for analysis
- Build relationships between datasets
- Create KPI and performance analysis
- Apply basic DAX and Measures
- Develop interactive Power BI dashboards
- Apply dashboard design principles based on business requirements
- Present data in a clear and meaningful format
